# EstrangeirismoProjeto  

Bem-vindo ao **EstrangeirismoProjeto**, uma iniciativa do **CEF Gama** para explorar o uso de palavras em inglês no cotidiano, apresentada por meio de um site simples e responsivo, com suporte para dispositivos móveis.  

## Sobre o Projeto  
Este projeto tem como objetivo demonstrar como o inglês influencia a nossa comunicação diária, apresentando exemplos de estrangeirismos que utilizamos frequentemente.  

O site foi desenvolvido com foco na simplicidade e acessibilidade, garantindo uma navegação intuitiva tanto em desktops quanto em dispositivos móveis.  

## Acesse o Site  
Você pode visualizar o projeto diretamente no seguinte link:

## Funcionalidades  
- **Exibição de estrangeirismos**: Palavras em inglês usadas no cotidiano, apresentadas de forma clara e organizada.  
- **Design responsivo**: Compatível com smartphones, tablets e computadores.  
- **Interface simples**: Navegação direta e sem complicações.  

## Tecnologias Utilizadas  
- **HTML5**  
- **CSS3**
